# Hero video

The hero will automatically use a video here if present — drop a file named:

- `space.mp4`  (preferred, works in every browser)
- `space.webm` (optional alternate)

If neither file exists, the site falls back to:

1. A real **NASA / Cassini Saturn** clip streamed from Wikimedia Commons
   (public domain) — plays in Chrome/Firefox.
2. A fully procedural animated Saturn + starfield rendered in `<canvas>`
   (always works, even offline / on Safari).

So the hero always shows something. To guarantee your exact footage,
add your own `space.mp4` here.

### Good public-domain sources
- NASA SVS — https://svs.gsfc.nasa.gov  (search "Saturn")
- NASA Science Cassini videos — https://science.nasa.gov/mission/cassini/multimedia/videos/
- Wikimedia Commons — https://commons.wikimedia.org (search "Saturn Cassini")

Keep the file reasonably small (a 10–25 MB, ~20s loop at 1080p is ideal
for a background).
